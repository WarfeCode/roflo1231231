# 🐶 УМКА-РАДАР (Umka Media Tracker)

Интерактивный веб-сайт и радар медиаполя для мониторинга упоминаний шпица Александра Лукашенко (Умки).

## 🚀 Как открыть проект в VS Code

1. Откройте **Visual Studio Code**.
2. В верхнем меню выберите **File** (Файл) → **Open Folder...** (Открыть папку...).
3. Перейдите на Рабочий стол и выберите папку `umka-tracker` (путь: `C:\Users\warfe\OneDrive\Desktop\umka-tracker`).
4. Либо выполните в командной строке / терминале:
   ```bash
   code "C:\Users\warfe\OneDrive\Desktop\umka-tracker"
   ```

## 🌐 Как запустить сайт

* **Способ 1 (через Live Server в VS Code):**
  Установите расширение **Live Server** в VS Code, откройте `index.html`, нажмите правой кнопкой мыши и выберите **«Open with Live Server»**.
* **Способ 2 (в любом браузере напрямую):**
  Дважды кликните по файлу `index.html` на Рабочем столе в папке `umka-tracker`.

## ✨ Возможности

* ⏱️ **Счетчик и ключевой заголовок:** заголовок «18х дней Умка пропал» с живым таймером (дни, часы, минуты, секунды) отсутствия на публике.
* 🌓 **Переключение темы:** поддержка темной и светлой темы с сохранением в `localStorage`.
* 🔍 **Медиа-сканер:** опрашивает открытые источники (Wikipedia API и базу фактов), анализирует упоминания и выдает вердикт: появлялся ли пёс, опровергнуты ли слухи об исчезновении.
* 🐾 **Досье и хроника:** факты и история ключевых появлений (субботник 2020, обед на столе 2021, учения «Запад-2021», Большой театр, визиты в ОАЭ и Зимбабве, выборы 2025).
* 📱 **Адаптивный дизайн:** отлично выглядит на смартфонах, планшетах и мониторах.
